========================================================================
CYBER-STRIKE CTF // CHALLENGE FILES DIRECTORY
========================================================================

Place any files that participants need to download for challenges right here in this folder:
D:\live projects\CTF_WEBSITES\public\challenges\

For example:
- network_capture.pcap
- suspicious_image.png
- crackme.bin
- source_code.zip

How to link them in a challenge:
1. In the Admin Center (/admin), or in your challenges list:
   - Set "File URL / Link" to: /challenges/your_file_name.ext
   - Set "File Name" to: your_file_name.ext
2. When participants open the challenge card in the Arena (/arena), a "Download File" button will automatically appear for them!
